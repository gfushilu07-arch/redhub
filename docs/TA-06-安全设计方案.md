## 1. 认证体系

### 1.1 JWT 设计

```rust
#[derive(Serialize, Deserialize)]
pub struct Claims {
    pub sub: Uuid,           // 用户 ID
    pub tenant_id: Uuid,     // 租户 ID
    pub roles: Vec<String>,  // 角色编码列表
    pub permissions: Vec<String>, // 权限编码列表
    pub exp: i64,
    pub iat: i64,
    pub jti: String,         // Token 唯一标识（用于撤销）
}
```

| 参数 | 值 | 说明 |
|------|-----|------|
| 签名算法 | RS256 (RSA + SHA-256) | 非对称签名，公钥可分发验证 |
| Access Token 有效期 | 30 分钟 | 短有效期降低泄露风险 |
| Refresh Token 有效期 | 7 天 | 仅用于刷新，不可访问业务 API |
| 刷新策略 | Rotation | 每次刷新生成新 Refresh Token，旧 Token 作废 |

### 1.2 密码安全

```rust
use argon2::{Argon2, PasswordHasher, PasswordVerifier};

// 使用 Argon2id（等保二级推荐）
pub fn hash_password(plain: &str) -> Result<String> {
    let salt = SaltString::generate(&mut OsRng);
    let argon2 = Argon2::default();
    let hash = argon2.hash_password(plain.as_bytes(), &salt)?;
    Ok(hash.to_string())
}

pub fn verify_password(plain: &str, hash: &str) -> Result<bool> {
    let parsed = PasswordHash::new(hash)?;
    let argon2 = Argon2::default();
    Ok(argon2.verify_password(plain.as_bytes(), &parsed).is_ok())
}
```

**密码策略：**
- 最小长度 8 位
- 必须包含字母和数字
- 连续错误 5 次锁定 30 分钟
- 强制首次登录修改初始密码

### 1.3 多因素认证

| 方式 | 优先级 | 场景 |
|------|--------|------|
| 短信验证码 | P0 | 登录二次验证、敏感操作确认 |
| 人脸识别 | P1（可配置） | 考试入场、活动签到 |
| TOTP 动态口令 | P2 | ADM 后台管理员登录 |

```text
用户 ──M:N──► 角色 ──M:N──► 权限
```

### 2.2 中间件实现

```rust
pub struct RbacLayer;

impl<S> Layer<S> for RbacLayer {
    type Service = RbacService<S>;
    fn layer(&self, inner: S) -> Self::Service {
        RbacService { inner }
    }
}

impl<S> Service<Request<Body>> for RbacService<S> {
    async fn call(&mut self, req: Request<Body>) -> Response {
        let claims = req.extensions().get::<Claims>().cloned();
        let path = req.uri().path();

        match check_permission(claims, path, req.method()) {
            PermissionResult::Allowed => self.inner.call(req).await,
            PermissionResult::Denied(reason) => (
                StatusCode::FORBIDDEN,
                Json(ApiResponse::error(40300, reason)),
            ).into_response(),
            PermissionResult::CrossTenant => (
                StatusCode::FORBIDDEN,
                Json(ApiResponse::error(40301, "Cross-tenant access denied")),
            ).into_response(),
        }
    }
}
```

### 2.3 租户隔离强制

所有数据库查询通过 SeaORM 的全局 scope 自动注入 `tenant_id` 条件：

```rust
// crates/platform/src/db/tenant_scope.rs
pub struct TenantScope {
    tenant_id: Uuid,
}

/// 所有实体查询自动追加 WHERE tenant_id = $1
impl QueryFilter for TenantScope {
    fn apply(&self, select: &mut SelectStatement) {
        select.and_where(Expr::col((Alias::new("base"), Alias::new("tenant_id")))
            .eq(self.tenant_id));
    }
}
```

**禁止事项：**
- 手动拼接 SQL 绕过 TenantScope
- 在 Repository 层暴露不带 `tenant_id` 参数的查询方法
- 缓存 Key 不含 `tenant_id`

## 3. 数据加密

### 3.1 传输加密

- 全站 HTTPS，TLS 1.3 最低版本
- HSTS 头：`Strict-Transport-Security: max-age=31536000; includeSubDomains; preload`
- 内部服务间通信：mTLS（K8s 环境）

### 3.2 存储加密

| 数据类型 | 加密方式 | 密钥管理 |
|----------|----------|----------|
| 用户密码 | Argon2id 单向哈希 | 无需密钥 |
| 身份证号 | AES-256-GCM 对称加密 | KMS 或环境变量密钥 |
| 手机号 | AES-256-GCM + 格式保留加密(FPE) | 同上 |
| 会话数据 | Redis TLS + AUTH | Redis requirepass |
| 数据库文件 | PostgreSQL pgcrypto 或磁盘加密(LUKS) | 运维层管理 |

### 3.3 敏感字段脱敏

```rust
pub fn mask_id_card(id_card: &str) -> String {
    if id_card.len() < 8 { return "*".repeat(id_card.len()); }
    format!("{}********{}", &id_card[..4], &id_card[id_card.len()-4..])
}

pub fn mask_mobile(mobile: &str) -> String {
    if mobile.len() != 11 { return mobile.to_string(); }
    format!("{}****{}", &mobile[..3], &mobile[7..])
}
```

```rust
pub async fn is_rate_limited(
    redis: &Pool,
    key: &str,
    limit: u32,
    window_secs: u64,
) -> Result<bool> {
    let mut conn = redis.get().await?;

        .cmd("ZADD").arg(key).arg(now).arg(now)
        .cmd("ZCARD").arg(key)
        .query_async(&mut conn).await?;

    // 如果计数超过限制则返回 true
    // ...
}
```

### 4.2 防 CSRF

API 层使用 Bearer Token 认证天然免疫 CSRF。Web 前端如使用 Cookie 存储则需要：

- SameSite=Strict Cookie
- 自定义 Header 校验（`X-Requested-With: XMLHttpRequest`）

### 4.3 防 SQL 注入

- 全部使用 ORM 参数化查询，禁止字符串拼接 SQL
- 如需原生查询使用 `sqlx::query!()` 宏（编译时检查）
- 输入验证：serde 反序列化时严格类型检查

### 4.4 开放 API 安全

```rust
#[derive(Debug)]
pub struct OpenApiAuth {
    pub app_id: String,
    pub timestamp: i64,
    pub nonce: String,
    pub signature: String,
}

pub fn verify_signature(auth: &OpenApiAuth, secret: &str) -> Result<()> {
    // 时间窗口校验：±5 分钟
    let now = chrono::Utc::now().timestamp();
    if (auth.timestamp - now).abs() > 300 {
        return Err(anyhow!("Timestamp out of range"));
    }

    // Nonce 唯一性校验（Redis SETNX，5 分钟过期）
    // ...

    // HMAC-SHA256 签名验证
    let payload = format!("{}{}{}", auth.app_id, auth.timestamp, auth.nonce);
    let expected = hmac_sha256(secret.as_bytes(), payload.as_bytes());
    if !constant_time_eq(&expected, hex_decode(&auth.signature)?) {
        return Err(anyhow!("Invalid signature"));
    }
    Ok(())
}
```

## 5. 审计日志

### 5.1 记录范围

| 事件类型 | 必须记录字段 |
|----------|-------------|
| 登录/登出 | user_id, IP, User-Agent, 结果 |
| 关键写操作 | user_id, action, resource_type, resource_id, request_body |
| 导出操作 | user_id, export_type, row_count, file_path |
| AI 调用 | user_id, capability, model, tokens_used |
| 开放 API 调用 | app_id, endpoint, method, response_status |
| 权限变更 | operator_id, target_user_id, role_changes |
| 配额变更 | operator_id, old_value, new_value |

### 5.2 日志防篡改

审计日志表只允许 INSERT，禁止 UPDATE 和 DELETE：

```sql
-- 通过 PostgreSQL 行级安全策略或触发器保护
CREATE OR REPLACE FUNCTION prevent_audit_modification()
RETURNS TRIGGER AS $$
BEGIN
    RAISE EXCEPTION 'Audit logs cannot be modified or deleted';
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER audit_immutable
    BEFORE UPDATE OR DELETE ON sys_audit_log
    FOR EACH ROW EXECUTE FUNCTION prevent_audit_modification();
```

P2 可选：定期将日志哈希上链存证。

## 6. 网络安全

### 6.1 WAF 规则建议

| 规则类别 | 说明 |
|----------|------|
| SQL 注入检测 | 请求参数中含 SQL 关键字模式 |
| XSS 过滤 | HTML 标签和脚本注入 |
| 路径穿越 | `../` 和 URL 编码变体 |
| 文件上传校验 | Content-Type 白名单 + 文件头魔数校验 |
| CC 攻击防护 | 高频请求 IP 封禁 |

### 6.2 安全响应头

```rust
pub fn security_headers(response: &mut Response) {
    response.headers_mut().insert("X-Content-Type-Options", "nosniff".parse().unwrap());
    response.headers_mut().insert("X-Frame-Options", "DENY".parse().unwrap());
    response.headers_mut().insert("X-XSS-Protection", "1; mode=block".parse().unwrap());
    response.headers_mut().insert(
        "Strict-Transport-Security",
        "max-age=31536000; includeSubDomains; preload".parse().unwrap(),
    );
    response.headers_mut().insert(
        "Content-Security-Policy",
        "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'".parse().unwrap(),
    );
}
```

## 7. WASM 沙箱安全

规则和插件在 wasmtime 中执行时的安全约束：

```rust
use wasmtime::{Config, Engine, Store};

pub fn create_sandbox_engine() -> Engine {
    Config::new()
        .wasm_threads(false)          // 禁用线程
        .wasm_bulk_memory(true)       // 允许批量内存操作
        .consume_fuel(true)           // 启用燃料计量（防止无限循环）
        .max_wasm_stack(1024 * 1024)  // 限制栈大小 1MB
        .into_engine()
}

pub async fn execute_rule(engine: &Engine, wasm_bytes: &[u8], context: &serde_json::Value) -> Result<bool> {
    let mut store = Store::new(engine, ());
    store.set_fuel(10_000_000)?;      // 最大执行步数限制

    let module = Module::from_binary(engine, wasm_bytes)?;
    let instance = Instance::new(&mut store, &module, &[])?;

    // 只允许调用 evaluate 函数，无网络/文件系统/系统调用权限
    let func = instance.get_func(&mut store, "evaluate")
        .ok_or_else(|| anyhow!("Missing 'evaluate' export"))?;

    // 执行并返回结果
    // ...
}
```

**沙箱约束清单：**
- 无网络访问权限
- 无文件系统访问权限
- 内存上限 16MB
- 执行步数上限 10M fuel
- 无系统调用
- 超时自动终止
