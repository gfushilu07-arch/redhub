## 1. 用户角色定义

| 角色 | 描述 | 主要端 | 核心诉求 |
|------|------|--------|----------|
| 普通党员 | 参加组织生活、完成学习任务、查询党费 | MP | 方便快捷地完成组织要求 |
| 支部书记 | 管理本支部党员、安排会议、审核材料 | MP/WT/ADM | 减少手工统计和通知工作 |
| 党务工作者 | 发展党员流程管理、材料审核、台账维护 | WT/ADM | 流程不超期、材料不遗漏 |
| 群众/居民 | 报名活动、提交诉求、办事咨询 | MP | 找得到入口、办得成事 |
| 街道管理员 | 区域统筹、考核督办、数据查看 | ADM/BI | 一目了然掌握全局 |
| 平台运营 | 租户开通、套餐管理、系统运维 | OPS | 高效开户、快速排障 |

## 3. P0 功能优先级矩阵

按用户价值和实现复杂度排列：

```text
                    高价值
                      │
    三会一课全流程 ●   │   ● 扫码签到
    党员档案管理 ●     │   ● 学习进度核验
    党费线下登记 ●     │   ● 活动报名
    组织权限管理 ●     │   ● 诉求上报
    SaaS 租户底座 ●    │
                      │
 低复杂度 ─────────────┼─────────────── 高复杂度
                      │
    通知公告 ●         │   ● 办事事项引擎
    字典参数管理 ●     │   ● 网格事件闭环
    Excel 导入导出 ●  │   ● 工作流引擎
    数据回收站 ●       │   ● AI Gateway 骨架
                      │
                    低价值
```

**MVP 建议：优先做高价值 + 低复杂度的功能，快速交付核心价值。**

## 5. 迭代规划建议

| 迭代 | 目标 | 核心交付物 |
|------|------|-----------|
| Sprint 1-3 | 底座可用 | 租户模型 + 组织权限 + 登录认证 + 字典参数 |
| Sprint 4-6 | 党员管理上线 | 党员档案 CRUD + Excel 导入导出 + 组织树管理 |
| Sprint 7-9 | 组织生活闭环 | 三会一课创建 + 签到 + 请假 + 会议纪要 |
| Sprint 10-12 | 学习教育上线 | 课程管理 + 视频学习 + 进度上报 + 考试 |
| Sprint 13-15 | 服务群众上线 | 活动 + 诉求 + 办事基础 + 微心愿 |
| Sprint 16-18 | 网格事件 + 工作流 | 网格树 + 事件流转 + 新一代工作流引擎 MVP |
| Sprint 19+ | 增强 | AI 功能 / Sunlab Agent / 开放 API / 考核督办 |
