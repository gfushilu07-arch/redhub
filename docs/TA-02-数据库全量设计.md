## 1. 设计规范

### 1.1 通用约定

- 所有表使用 `snake_case` 命名
- 主键统一 `UUID v7`（时间有序，适合 B-tree 索引）
- 所有业务表必须包含 `tenant_id UUID NOT NULL`
- 软删除：`deleted_at TIMESTAMPTZ`（NULL 表示未删除）
- 审计字段：`created_by UUID`, `created_at TIMESTAMPTZ`, `updated_by UUID`, `updated_at TIMESTAMPTZ`
- 枚举使用 `VARCHAR` + CHECK 约束（避免 PostgreSQL ENUM 类型迁移困难）

### 1.2 索引策略

- `tenant_id` 必须出现在所有复合索引的第一列
- 外键列自动建索引
- 高频查询字段（状态、时间范围）建复合索引

## 2. 平台底座域（platform）

### 2.1 tenant — 租户

```sql
CREATE TABLE tenant (
    id              UUID PRIMARY KEY,
    code            VARCHAR(50) NOT NULL UNIQUE,        -- 租户编码
    name            VARCHAR(200) NOT NULL,
    type            VARCHAR(50) NOT NULL,               -- street/government/enterprise/social_org
    region_code     VARCHAR(20),                        -- 行政区划代码
    contact_name    VARCHAR(100),
    contact_phone   VARCHAR(20),
    status          VARCHAR(20) NOT NULL DEFAULT 'trial'
                    CHECK (status IN ('trial','active','frozen','closed')),
    scene_package   VARCHAR(50) NOT NULL DEFAULT 'street', -- street/government
    quota_json      JSONB NOT NULL DEFAULT '{}',        -- 配额：党员数/存储/AI调用/API频次
    settings_json   JSONB NOT NULL DEFAULT '{}',        -- 租户级配置
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    deleted_at      TIMESTAMPTZ
);
```

### 2.2 org — 组织树

```sql
CREATE TABLE org (
    id              UUID PRIMARY KEY,
    tenant_id       UUID NOT NULL REFERENCES tenant(id),
    parent_id       UUID REFERENCES org(id),
    name            VARCHAR(200) NOT NULL,
    type            VARCHAR(50) NOT NULL,               -- committee/branch/general_branch/group
    org_type        VARCHAR(50) NOT NULL DEFAULT 'street', -- street/government/community/enterprise/two_new
    path            TEXT NOT NULL,                      -- 物化路径 /root_id/parent_id/self_id
    depth           INT NOT NULL DEFAULT 0,
    sort_order      INT NOT NULL DEFAULT 0,
    status          VARCHAR(20) NOT NULL DEFAULT 'active',
    created_by      UUID,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    deleted_at      TIMESTAMPTZ
);
CREATE INDEX idx_org_tenant ON org(tenant_id, deleted_at);
CREATE INDEX idx_org_parent ON org(tenant_id, parent_id);
CREATE INDEX idx_org_path ON org(tenant_id, path text_pattern_ops);
```

```sql
CREATE TABLE party_member (
    id              UUID PRIMARY KEY,
    tenant_id       UUID NOT NULL REFERENCES tenant(id),
    user_id         UUID REFERENCES sys_user(id),       -- 关联系统账号（可选）

    position        VARCHAR(200),                       -- 党内职务
    work_unit       VARCHAR(200),
    tags            JSONB NOT NULL DEFAULT '[]',        -- ["在职","流动","困难","双报到"]
    status          VARCHAR(30) NOT NULL DEFAULT 'active',

    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT now(),

);
CREATE INDEX idx_member_tenant_org ON party_member(tenant_id, org_id, deleted_at);
```

```sql
    is_read         BOOLEAN NOT NULL DEFAULT FALSE,
    read_at         TIMESTAMPTZ,
    sent_at         TIMESTAMPTZ NOT NULL DEFAULT now(),
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_notification_tenant_recipient ON notification(tenant_id, recipient_id, is_read);
```
