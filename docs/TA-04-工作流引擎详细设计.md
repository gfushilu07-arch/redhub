## 1. 架构定位

工作流引擎是共享内核域的核心组件，被所有需要审批流转的业务域复用。它不依赖任何业务域，通过泛型和 Trait 与上层业务解耦。

```text
┌─────────────────────────────────────────────────────┐
│                业务域（party / service / grid）        │
│         通过 WorkflowService trait 调用               │
├─────────────────────────────────────────────────────┤
│                  工作流引擎（workflow crate）           │
│                                                     │
│  ┌───────────┐  ┌───────────┐  ┌───────────────┐   │
+│  │ StateMachine│  │ RuleEngine │  │ SignalHandler  │   │
│  └───────────┘  └───────────┘  └───────────────┘   │
│  ┌───────────┐  ┌───────────┐                      │
│  │ EventStore │  │ TimerManager│                     │
│  └───────────┘  └───────────┘                      │
├─────────────────────────────────────────────────────┤
│                    数据层                             │
│         PostgreSQL (6 tables) + Redis (可选)          │
└─────────────────────────────────────────────────────┘
```

## 3. 状态机引擎

### 3.1 核心逻辑

```rust
pub struct StateMachine {
    definition: Arc<WorkflowDefinition>,
    event_store: Arc<dyn EventStore>,
    rule_engine: Arc<RuleEngine>,
    signal_rx: mpsc::Receiver<SignalEnvelope>,
}

impl StateMachine {
    /// 推进状态机到下一个状态
    pub async fn advance(&mut self, instance: &mut WorkflowInstance) -> Result<()> {
        loop {
            match &instance.current_state {
                WorkflowState::Submitted => {
                    // 匹配第一条满足条件的规则
                    let rule = self.find_matching_rule(&instance.context)?;
                    self.create_task(instance, &rule).await?;
                    instance.current_state = WorkflowState::AwaitingApproval {
                        node: format!("rule_{}", rule.order),
                        approver_expr: rule.approver.clone(),
                    };
                    break;
                }
                WorkflowState::AwaitingApproval { .. } => {
                    // 等待信号注入
                    let signal = self.signal_rx.recv().await;
                    match signal.signal_type {
                        SignalType::HumanApprove { .. }
                        | SignalType::AgentSuggest { confidence, .. } if confidence > 0.9 => {
                            // 查找下一条规则；如果没有则完成
                            if let Some(next_rule) = self.find_next_rule(instance)? {
                                self.create_task(instance, &next_rule).await?;
                                instance.current_state = WorkflowState::AwaitingApproval {
                                    node: format!("rule_{}", next_rule.order),
                                    approver_expr: next_rule.approver.clone(),
                                };
                            } else {
                                instance.current_state = WorkflowState::Approved;
                                self.record_event(instance, "APPROVED").await?;
                                break;
                            }
                        }
                        SignalType::HumanReject { reason } => {
                            instance.current_state = WorkflowState::Rejected { reason };
                            self.record_event(instance, "REJECTED").await?;
                            break;
                        }
                        _ => { /* 其他信号处理 */ }
                    }
                }
                _ => break,
            }
        }
        Ok(())
    }

    fn find_matching_rule(&self, context: &serde_json::Value) -> Result<Option<&WorkflowRule>> {
        for rule in &self.definition.rules {
            if RuleEngine::evaluate(&rule.condition, context)? {
                return Ok(Some(rule));
            }
        }
        Err(anyhow!("No matching rule found"))
    }
}
```

### 3.2 审批人解析

```rust
pub struct ApproverResolver;

impl ApproverResolver {
    pub async fn resolve(
        expr: &str,
        context: &serde_json::Value,
        platform: &dyn PlatformService,
    ) -> Result<Vec<Uuid>> {
        if expr == "self" {
            return Ok(vec![]); // 自动通过
        }

        let parts: Vec<&str> = expr.splitn(2, ':').collect();
        match parts[0] {
            "role" => {
                let role_code = parts[1];
                platform.find_users_by_role(role_code).await
            }
            "user" => {
                // 解析动态路径如 "{initiated_by.supervisor}"
                let user = resolve_json_path(context, parts[1])?;
                Ok(vec![user.as_uuid()?])
            }
            "org" => {
                let org_leader = platform.find_org_leader(parts[1]).await?;
                Ok(vec![org_leader])
            }
            _ => Err(anyhow!("Unknown approver expression: {}", expr)),
        }
    }
}
```

### 4.2 快照优化

当事件数超过阈值时保存快照，加速回放：

```rust
const SNAPSHOT_THRESHOLD: usize = 50;

impl PostgresEventStore {
    async fn maybe_save_snapshot(&self, instance_id: Uuid) -> Result<()> {
        let count = sqlx::query_scalar!(
            "SELECT COUNT(*) FROM workflow_event WHERE instance_id = $1",
            instance_id
        )
        .fetch_one(&self.pool)
        .await?;

        if count % SNAPSHOT_THRESHOLD == 0 {
            let state = self.rebuild_state(instance_id).await?;
            sqlx::query!(
                r#"INSERT INTO workflow_snapshot (instance_id, state, created_at)
                   VALUES ($1, $2, now())
                   ON CONFLICT (instance_id) DO UPDATE SET state = $2, created_at = now()"#,
                instance_id,
                serde_json::to_value(&state)?
            )
            .execute(&self.pool)
            .await?;
        }
        Ok(())
    }

    async fn rebuild_state(&self, instance_id: Uuid) -> Result<WorkflowInstanceState> {
        // 从最近快照开始回放
        let snapshot = self.get_latest_snapshot(instance_id).await?;
        let mut state = snapshot.map(|s| s.state)
            .unwrap_or(WorkflowInstanceState::default());
        let events_after = self.get_events_after(instance_id, snapshot.map(|s| s.created_at)).await?;
        for event in events_after {
            state.apply(event)?;
        }
        Ok(state)
    }
}
```

## 5. Durable Execution

### 5.1 恢复机制

应用重启后从数据库恢复所有未完成的工作流实例：

```rust
pub struct RecoveryWorker {
    pool: PgPool,
    state_machines: Arc<RwLock<HashMap<Uuid, StateMachineHandle>>>,
}

impl RecoveryWorker {
    pub async fn recover_all(&self) -> Result<usize> {
        let instances = sqlx::query_as!(
            WorkflowInstance,
            "SELECT * FROM workflow_instance WHERE current_state NOT IN ('approved','rejected','cancelled')"
        )
        .fetch_all(&self.pool)
        .await?;

        for instance in instances {
            let events = self.event_store.replay(instance.id).await?;
            let sm = StateMachine::from_replay(self.definition.clone(), events)?;
            let handle = self.spawn_state_machine(sm, instance).await?;
            self.state_machines.write().await.insert(instance.id, handle);
        }
        Ok(instances.len())
    }
}
```

### 5.2 计时器管理

使用 PostgreSQL 定时扫描实现 SLA 管理：

```rust
pub struct TimerManager {
    pool: PgPool,
    interval: Duration,
}

impl TimerManager {
    pub async fn start(&self) {
        loop {
            tokio::time::sleep(self.interval).await;
            if let Err(e) = self.check_expired_tasks().await {
                tracing::error!("Timer scan error: {}", e);
            }
        }
    }

    async fn check_expired_tasks(&self) -> Result<()> {
        let expired = sqlx::query_as!(
            WorkflowTask,
            r#"SELECT wt.* FROM workflow_task wt
               JOIN workflow_instance wi ON wt.instance_id = wi.id
               WHERE wt.status = 'pending'
               AND wt.sla_deadline < now()
               AND wi.current_state LIKE 'AwaitingApproval%'"#
        )
        .fetch_all(&self.pool)
        .await?;

        for task in expired {
            self.inject_timeout_signal(task.instance_id, task.id).await?;
        }
        Ok(())
    }

    async fn inject_timeout_signal(&self, instance_id: Uuid, task_id: Uuid) -> Result<()> {
        // 注入 system.timeout_escalate 或 system.timeout_remind 信号
        let signal = SignalEnvelope {
            instance_id,
            signal_type: SignalType::SystemTimeoutEscalate {
                escalate_to: self.find_escalation_target(task_id).await?,
            },
        };
        self.signal_tx.send(signal).await?;
        Ok(())
    }
}
```

## 8. 测试要点

详细测试方案见 QA-03，核心测试场景：

| 场景 | 验证点 |
|------|--------|
| 正常多级审批 | 状态按规则顺序正确流转 |
| 条件路由 | 不同条件命中不同审批人 |
| 超时升级 | SLA 到期后自动注入超时信号并升级 |
| 故障恢复 | 应用重启后从未完成状态继续 |
| 事件回放 | 回放结果与实际状态一致 |
| Agent 建议注入 | 高置信度 Agent 建议自动推进；低置信度等待人工确认 |
